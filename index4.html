Importante: a saída é uma classificação estatística baseada nos rótulos fornecidos. Não é diagnóstico, triagem clínica validada nem recomendação médica. Se o conjunto incluir mensagens de urgência, o resultado não deve substituir avaliação profissional.

Como funciona o experimento?

1. Dados rotulados

O algoritmo recebe mensagens associadas a classes previamente definidas.

2. Treinamento

O Naive Bayes Multinomial estima a frequência das palavras em cada classe e aplica suavização de Laplace para lidar com palavras pouco frequentes.

3. Avaliação

Uma parte dos exemplos é reservada para teste. Acurácia, precisão, recall e F1 são calculados com base nas previsões desse conjunto.

4. Nova classificação

Após a avaliação, o modelo é treinado com todos os registros válidos e pode classificar novas mensagens.

As probabilidades são estimativas internas do modelo e não devem ser interpretadas como confiança clínica calibrada. O desempenho depende da qualidade, representatividade e equilíbrio dos dados.
